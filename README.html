Install this delivered source release

Python 3.10+ targeted; tested Python 3.12/Linux/CPU. Create and activate a venv, then python -m pip install ., or install the matching wheel from dist. No mandatory runtime dependencies. Add optional engines only when needed, e.g. python -m pip install '.[nlp,ml]'. No automatic download or paid API requirement. This is a privately delivered alpha, not a claimed public PyPI/GitHub publication.

Real services and clear limits

64 registered capabilities; the current report separates the 61 exercised example paths from three actual-weight-unverified adapters. Arabic NLP projects, CSV and sales forecasts, labeled ML/neural training, pretrained vision, OCR, speech, RAG, bounded agents, source review, API schema, ONNX/Keras and industrial transports. Verification counts and platform limits: current report. General natural language routes conservatively; missing labels/references/permissions are not invented. A small local model is the text fallback, not an unrestricted agent.

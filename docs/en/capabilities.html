Acceptance-based roadmap

  • 0.2: owner license decision, run actual cross-platform CI, per-platform hash locks, reproducible Arabic/real-world evaluations, installer/skops integration tests.
  • 0.3: licensed, hashed local text/vision/speech/embedding weights and real CPU/GPU inference tests; constrained JSON planning with explicit privilege separation.
  • 0.4: Arabic OCR/layout extraction, temporary-ID multi-object tracking (not face identification), licensed TTS, evidence-grounded RAG with abstention evaluation.
  • 0.5: process sandbox/resource limits, cancellation/async, MQTT/ONNX/edge/robot adapters with safety tests. No physical actuation without explicit approval.
  • 1.0: stable API contracts, independent security/license review, reproducible benchmarks, migrations, incident response and enterprise integration tests.

Additional needs identified: MLOps/experiment tracking, privacy/redaction, fairness and accessibility, interpretability, group/time-aware evaluation, quantization and Arabic quality assessment. These are roadmap items, not placeholder functions.

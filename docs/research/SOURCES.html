Independent synthesis | الخلاصة المستقلة

The best starting point is a facade with honest typed contracts and lazy adapters, not a promise that any natural-language request can safely run arbitrary tools. A framework's permissive license does not grant rights to model weights, datasets, codecs, trademarks, or another author's work. No model weights or external library sources are vendored here. Legal review before distribution/commercial deployment remains necessary, especially for restrictive founder terms and copyleft tools.

Observed compatibility evidence: OpenCV 5.0 in the initial host lacked CascadeClassifier. A clean environment with OpenCV 4.12 fixed the actual integration, and the declared vision range was tightened to >=4.10,<5. No quality claim is based only on an import succeeding. Model inference not executed is explicitly marked.

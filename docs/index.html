بوابة Python موحدة لتبسيط أدوات الذكاء الاصطناعي، مع نواة خفيفة ومحركات اختيارية ونتائج قابلة للتصدير.

One Python entry point. Explicit capabilities, optional local engines, bounded agent workflows and honest provenance.

ابدأ بالعربية · English guide · تقرير التسليم

ابدأ بسطر واحد

from alfarouqai import AI r = AI("حلل هذا النص", text="الذكاء الاصطناعي يساعد الطلاب.") print(r.data)

للمهام المتقدمة استخدم Client.run مع اسم قدرة صريح. لا تنزيل ولا شبكة افتراضية.

Implementation, not promises

Real local text, CSV, ML, AST, document, face, motion and retrieval tools. Actual trained-model verification is separated from experimental adapters.

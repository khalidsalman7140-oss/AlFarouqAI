إضافة قدرة حقيقية

from alfarouqai import Client, Capability, Result

def count_words(*, text, config):
    return Result('custom.words', {'count':len(text.split())}, 'my-plugin')

client = Client()
client.registry.register(Capability('custom.words', count_words, 'Word count', ('text',)))
print(client.run('custom.words', text='Hello AlFarouq AI').data)

الدالة معلنة المدخلات، لا تثبت مكتبات خفياً، وتعيد Result، وتختبر بمدخلات حقيقية وتوثيق عربي/إنجليزي. الأسماء المكررة والمدخلات غير المعروفة مرفوضة. يمكن لحزمة منفصلة إعلان [project.entry-points."alfarouqai.plugins"] ثم counter = "my_plugin:register" حيث register(registry) تسجل Capability. client.registry.load_plugins(consent=True) يحمل إضافات مثبتة موثوقة فقط. تحميل إضافة يشغل Python بصلاحيات العملية؛ ليس sandbox.

تهيئة GitHub وPyPI دون نشر

المجلد يحتوي القوالب وCI وسياسات المساهمة والأمان وmetadata والحزم المبنية. لم ينشأ مستودع في حساب خارجي ولم يُحجز اسم ولم يُرفع شيء. بعد قرار الترخيص والموافقة الصريحة وتوفر الاسم: أنشئ مستودعاً في حسابك، راجع الصورة والبريد والعمر قبل إتاحتها علناً، ثم اربط المجلد وارفعه. بعد نجاح CI ابنِ إصداراً جديداً واختبره في TestPyPI باستخدام بيانات اعتمادك ووافق على الإصدار النهائي. لا توجد رموز سرية ولا publish workflow تلقائي. لا تفترض أن حق استخدام اسم PyPI أو علامة تجارية قد تم التحقق منه.

تدار النسخ عبر pyproject.toml و__version__ وCHANGELOG. استخدم SemVer مع توضيح أن 0.x تجريبي. لا تقبل مساهمات من الغير دون شروط مكتوبة متوافقة مع اختيار المالك الحالي. لا يجوز وضع MIT فوق أعمال أصلية مع طلب منع إعادة استخدامها.

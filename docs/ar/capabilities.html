الدليل · English

«مُختبر» يعني تنفيذ المحرك فعلياً في بيئة التسليم المحلية على عينات اختبار، لا ضمان جودة مطلقة أو قابلية تعميم. راجع reports/pytest.xml وFINAL_REPORT.

المجال المنفذ في 0.1.0 الحالة / الحد
NLP إحصاءات وكلمات وتلخيص استخراجي مختبر؛ لا ترجمة أو تصنيف مشاعر عصبي
LLM Ollama chat وvision input عقد HTTP مختبر؛ لا استدلال فعلي
Computer Vision إحصاءات صور ووجوه Haar مختبر على الصورة المقدمة؛ لا تحديد هوية
IoT تحليل CSV لمستشعرات وz-score مختبر؛ لا أجهزة متصلة
تطوير التطبيقات Python API وCLI وملفات تقارير مختبر؛ لا خادم ويب إنتاجي
الشبكات العصبية موصلات أطر فقط لا واجهة إنشاء/تدريب شبكة في هذا الإصدار
Deep Learning موصلات inference اختيارية لا تدريب عميق أو finetuning
Machine Learning تصنيف وانحدار RandomForest تدريب/تقييم/تنبؤ مختبر
Generative AI موصل لغوي محلي لا توليد صور/فيديو/صوت؛ لا استدلال مولد مختبر
Multimodal مدخل صورة لموصل Ollama يحتاج نموذجاً متوافقاً؛ غير مختبر فعلياً
صور وفيديو وجوه + مناطق حركة؛ موصل كشف عام الحركة مختبرة؛ الكشف العام بأوزان غير مختبر؛ لا تتبع
Speech AI WAV metadata + faster-whisper WAV مختبر؛ التفريغ غير مختبر بأوزان؛ لا TTS
Agents مخطط DAG وتخصصات ومراجع ومراجع بنية مختبر؛ لا مناظرة LLM مستقلة
علم البيانات CSV وتنبؤ جدولي مختبر؛ لا منصة AutoML شاملة
مستندات TXT/PDF/DOCX/XLSX استخراج مختبر؛ لا OCR أو DOC/XLS قديم
أكواد AST ومشروع ومخاطر نمطية مختبر؛ لا تنفيذ/تصحيح تلقائي أو تشغيل اختبارات مشروع مجهول
RAG وذاكرة JSON وTF-IDF؛ موصل semantic اللفظي مختبر؛ الدلالي غير مختبر بأوزان؛ لا RAG توليدي جاهز
أتمتة DAG محلي يستدعى عند الطلب مختبر؛ لا جدولة دائمة أو مراقبة أحداث
روبوتات لا تحكم منفذ خارطة مستقبل؛ أمان العتاد شرط
أمن دفاعي تحليل فشل المصادقة وAST مختبر؛ ليس SIEM أو ماسح ثغرات
خدمات إضافية تصدير/إعداد/إضافات/سياسات مختبر جزئياً كما يحدد تقرير التسليم

مراحل التطوير المقترحة ومعايير قبولها

  1. 0.2 جودة وتوزيع: قرار ترخيص، تشغيل CI فعلي عبر الأنظمة، lock/hash لكل منصة، تجارب بيانات عربية وواقعية دون تسرب، اختبارات نصب extras وskops.
  2. 0.3 ذكاء محلي مقاس: نموذج نصي وبصري وصوتي وتضمين موثقة الأوزان والترخيص والحجم والـhash، اختبارات استدلال على CPU/GPU، مخطط JSON مقيد بالصلاحيات.
  3. 0.4 فهم محتوى: OCR عربي، PDF مع layout، متتبع متعدد أهداف بمعرّفات مؤقتة لا تعرف هوية، TTS بأوزان تسمح بالاستخدام المطلوب، RAG موثّق مع رفض الإجابة.
  4. 0.5 نظم متقدمة: adapters لـMQTT/ONNX/edge/robotics وعمليات sandbox وasync وإلغاء؛ ممنوع تشغيل أجهزة حقيقية دون موافقات وحواجز أمان واختبار عتاد.
  5. 1.0 استقرار: عقود API ثابتة، تقييمات منشورة قابلة لإعادة الإنتاج، تدقيق أمان وترخيص مستقل، سياسة إصدار وترقية وعيوب معروفة وتجارب تكامل مؤسسي.

مجالات إضافية اكتشفها التحليل: MLOps وتتبع التجارب، تقييم النماذج والانحياز، الخصوصية والتنقيح، explainability، بيانات زمنية وتقسيم مجموعات، edge quantization، التيسير لذوي الإعاقة، وقياس جودة العربية. هذه متطلبات مستقبلية وليست أسماء وظائف وهمية داخل المكتبة الحالية.

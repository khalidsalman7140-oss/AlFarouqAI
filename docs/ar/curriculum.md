# منهج تعليمي عملي — لا بديل عن فهم الأسس
[الكتاب الكامل](handbook-0.2.md) · [English](../en/curriculum.md)

كل وحدة تشمل هدفاً وتجربة ثم تقريراً بالحدود. المقصود تبسيط التجربة لا إلغاء
الرياضيات أو جودة البيانات أو تراخيصها. أمثلة التدريب مصطنعة ومعلنة.

| الوحدة | الهدف والتجربة | أداة/مثال |
|---|---|---|
| 1 Python والبيئات | إنشاء venv واختيار مفسر VS Code | المثال 01 |
| 2 البيانات | CSV وقيم ناقصة وملف تقرير | data.profile |
| 3 NLP الأساسي | كلمات وإحصاءات وتلخيص استخراجي | text.analyze |
| 4 LLM | تشغيل أوزان ومقارنة إجابات ومراجعة هلوسة | المثال 10 |
| 5 تصنيف نص | فهم الفرق بين likelihood وثقة حقيقية | nlp.classify |
| 6 رؤية أساسية | أبعاد ووجوه لا هوية | المثال 06 |
| 7 كشف وتصنيف | فئات COCO مقابل ImageNet | المثال 11 |
| 8 تقسيم | تفسير قيم mask والفئات | vision.segment |
| 9 OCR | مقارنة مطبوع عربي/إنجليزي وجودة المسح | vision.ocr |
| 10 فيديو | حركة مقابل ربط tracks وحدود التداخل | video.track |
| 11 صوت | نطق ثم تفريغ وتسجيل الأخطاء لا إخفاؤها | المثال 12 |
| 12 ML | تقسيم وتسرب وترميز وتقييم | المثال 02 |
| 13 Deep Learning | loss وepochs وشبكة متعددة الطبقات | المثال 13 |
| 14 حفظ نماذج | safetensors وJSON وإعادة التنبؤ | المثال 13 |
| 15 توصيات وزمن | baselines وتحقق زمني وcold start | data.recommend / forecast |
| 16 مستندات | استخراج لا فهم كامل لكل الصفحات | المثال 09 |
| 17 Embeddings وRAG | بحث عابر للغات ومصادر وحدود الإسناد | المثال 14 |
| 18 Agents وأتمتة | DAG مقابل مخطط لغوي وصلاحيات وtick | الأمثلة 03 و15 و16 |
| 19 أجهزة وأمن | MQTT/Serial بموافقة وشذوذ ليس هجوماً مؤكداً | الأمثلة 17 و18 |
| 20 هندسة بحث | إعادة إنتاج وتراخيص وقياس ومقارنة وكتابة تقرير | reports وtests |

مشروع تخرج مقترح: مستندات تعليمية مرخصة -> استخراج -> فهرسة -> استرجاع ->
إجابة مع مصادر -> تقييم بشرى للأخطاء. لا تجعل جواب LLM مرجع حقيقة بذاته.
CNN/Transformer finetuning وSLAM وتوليد فيديو عميق تحتاج دروساً وعتاداً
إضافيين؛ لم نكتب أسماءها كوظائف مكتملة دون دليل تشغيل.

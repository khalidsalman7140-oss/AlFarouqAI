## الرؤية مقابل حدود الإصدار
الرؤية منصة موحدة، لا مكتبة تعيد تنفيذ كل خوارزمية. التصميم يفصل واجهة المستخدم
عن سياسات التشغيل وعن الأدوات والأوزان. الإصدار 0.1.0 إثبات هندسي تنفيذي، لا
اكتمال عشرين مجالاً. يفضّل نتيجة محدودة قابلة للتتبع على ادعاء «نفذ كل شيء».

```text
Python / CLI / VS Code
        |
 AI(prompt, inputs) ---- Client.run(explicit_task)
        |                         |
 محافظ ثنائي اللغة              Registry + Capability
        +-------------+-----------+
                      |
        تحقق مدخلات / Config / سياسة موافقة
                      |
   stdlib tools | optional local engines | Ollama opt-in
                      |
     Result(data, backend, warnings, provenance)
                      |
             JSON CSV MD HTML TXT

AgentTeam -> validate DAG -> specialists -> shared Result references -> schema reviewer
```

## مقارنة الخيارات والقرار
| القرار | البدائل المدروسة | الاختيار وسببه |
|---|---|---|
| واجهة موحدة | تغليف API فقط / نواة تعيد كل شيء | Registry وعقود Result وإضافات مستقلة؛ يحد التداخل |
| الاعتماديات | تنزيل الكل / تثبيت أثناء import | extras واستيراد كسول، وتثبيت منفصل بموافقة في venv |
| التخطيط | LLM إلزامي / قواعد صريحة | قواعد محافظة الآن؛ مخطط LLM مقيد مستقبلاً، لتعمل النواة دون أوزان |
| الوكلاء | منظومة LLM كبيرة / DAG محدود | DAG حقيقي قابل للاختبار بلا تكلفة API؛ ليس ذكاءً ذاتياً عاماً |
| جدولي | كتابة تدريب من الصفر / scikit-learn | Pipeline مع تقسيم قبل المعالجة، هدف ونوع واضحان |
| حفظ نماذج | pickle/joblib / skops / ONNX | skops اختياري للحفظ؛ لا تحميل غير موثوق، ONNX مستقبلاً |
| رؤية | YOLO افتراضي / OpenCV / Transformers | OpenCV للوجوه والحركة، موصل محلي عام منفصل؛ لا YOLO افتراضي |
| بحث | قاعدة متجهات إلزامية / ذاكرة نصية | JSON + TF-IDF للنواة، SentenceTransformers اختياري للدلالي |
| LLM | خدمة مدفوعة إلزامية / محلي | Ollama محلي باختيار النموذج والموافقة الصريحة |
| بيانات الإعداد | متغيرات سرية تلقائية / ملف صريح | dataclass وJSON دون تجميع خفي لبيئة الجهاز |
| الهوية والترخيص | رخصة مفتوحة تُخالف شرط المالك / محفوظ الحقوق | محفوظ الحقوق مؤقتاً؛ يمنع وصفه بأنه OSI open source |

بنيت extras وentry points على معيار Python، وحظر تحميل pickle على تحذيرات
scikit-learn الرسمية، وسياسة YOLO على شروطه المنشورة. روابط الأدلة في ملف
المصادر. لم أعتبر أن ترخيص مكتبة ما هو ترخيص الأوزان المستخدمة معها.

## تحسينات مطلوبة قبل إنتاج واسع
عزل العمليات مع CPU/RAM/timeouts، تثبيت hash-lock لكل منصة، اختبارات خصائص وفَزّ
للمحللات، كشف بيانات حساسة، نموذج تهديد، تقييم عربي مستقل، مراقبة تكلفة/زمن،
إلغاء المهام، async، تتبع نماذج وتجارب، cache مدروس، اختيار محرك حسب العتاد،
تنقيح بيانات وسجلات، تصدير ONNX، وتصميم manifest موثّق للأوزان والتراخيص.
لا يكفي اختيار «أقوى نموذج»؛ نحتاج معيار مهمة مرجعي وأجهزة معروفة ثم مقارنة
جودة/زمن/RAM/ترخيص. لم تتوفر في هذه الجلسة مقارنة استدلال بين نماذج كبيرة.

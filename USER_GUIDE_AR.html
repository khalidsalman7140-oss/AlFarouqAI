1. ما هي المكتبة؟

واجهة Python محلية أولاً توحّد خدمات نصوص وصور وصوت ومستندات وبيانات وتعلم آلي وواجهات نماذج ووكلاء وأدوات صناعية ودفاعية. هدفها تقليل الأكواد المتكررة وإظهار المحرك والنتيجة والتحذيرات. ليست نموذجاً واحداً يعرف كل شيء ولا ضماناً لدقة بحثية أو أمان إنتاجي أو قدرة تشغيل أكبر النماذج على أي جهاز.

المسار للمبتدئ: تثبيت النواة، تحليل نص، تصدير النتيجة، ثم تثبيت إضافة لمشروعه. المحترف يستطيع تحديد task والمحرك والنموذج والحدود وكتابة plugin دون استبدال النواة.

2. المتطلبات والتثبيت من النسخة المرفقة

Python 3.10 أو أحدث؛ الاختبار الفعلي هنا Python 3.12/Linux/CPU فقط. تنزيل ZIP وفكّه، ثم افتح Terminal في المجلد الذي يحتوي pyproject.toml. لا تختَر أي حزمة مشابهة على PyPI قبل التحقق من رابط النشر الرسمي؛ لم ينشر الإصدار في هذه المهمة.

python -m venv .venv
# Windows PowerShell: .\.\.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install .
python -m alfarouqai --version

بدلاً من تثبيت المصدر، ثبّت wheel داخل dist بالأمر python -m pip install dist/alfarouqai-0.3.0a1-py3-none-any.whl. لا تثبت المصدر والـwheel معاً في خطوة التحقق نفسها. النواة بلا تبعيات إلزامية؛ التبعيات الاختيارية في pyproject.toml. لتصنيف نصوص python -m pip install '.[nlp,ml]'؛ للرؤية '.[torchvision,vision]'، وللنماذج النصية '.[local]' وللبحث '.[vector]'. Tesseract OCR وespeak-ng ووسيط MQTT برامج نظام مستقلة، وليست pip packages مضمونة. لا يتم تنزيل وزن أو تثبيت dependency أو تنفيذ network عند import.

3. أول برنامج وعرض النتيجة

احفظ النص في app.py وشغّل python app.py:

from alfarouqai import AI, Client, Config
result = AI("حلل هذا النص", text="الذكاء الاصطناعي يساعد الطلاب.")
print(result.to_dict())
result.export("text-report.json")
client = Client(Config(verbose=True))
print(client.capabilities())

Result.data هي البيانات، backend يبين المحرك، warnings حدود النتيجة، provenance وقت التنفيذ وإصدار المكتبة ومعلومات المصدر حيث يتاح. export يرفض استبدال ملف قائم إلا overwrite=True، ويدعم JSON/CSV/Markdown/HTML/TXT. لا يفترض عرض النتائج تلقائياً داخل كل notebook؛ استخدم print أو display. verbose يعرض بداية/نهاية وأخطاء التنفيذ في stderr ولا يخفي تحذيرات المحركات.

4. الوصف المختصر مقابل الخدمة الصريحة

AI("حلل هذا الملف واستخرج أهم المعلومات", file="report.txt") يختار document.insights. AI("حلل المبيعات وتوقع الشهر القادم", data="sales.csv", date_column="date", value_column="sales") يستخدم sales.forecast إذا طابقت الأعمدة الصيغة. استعمل Client().plan(...) للمراجعة قبل التنفيذ وClient().run("اسم.الخدمة", ...) لتجنب الغموض. لا يختار target لتدريب تصنيف، ولا صورة مرجعية للعيوب، ولا كلمة مرور أو منفذ جهاز من عنده. prompt عام بلا ملف يذهب للنموذج النصي المحلي مع الموافقات/الأوزان؛ هذه ليست برمجة آلية مفتوحة لتنفيذ أي أمر طبيعي. المرجع الكامل يشرح المدخلات الدقيقة لكل خدمة بأمثلة منفذة.

5. النماذج والموارد

from alfarouqai import AI, Config, prepare_model, environment, model_plan, Model
print(environment())
print(model_plan(70, precision_bits=4).to_dict())
# Explicitly approves network + weights download; review license/storage first.
cfg = Config(allow_network=True, allow_model_download=True)
prepare_model("smollm2-135m", config=cfg)
result = AI("What is the capital of France?", model="smollm2-135m", device="auto", config=cfg)
print(result.to_dict())
# A reusable model avoids reloading for every call.
with Model("smollm2-135m", config=cfg, device="cpu") as model:
    print(model("Explain Python briefly.").data)

التنزيل في هذا المقطع يتطلب اتصالاً وموافقة صريحة؛ التحقق السابق استخدم أوزاناً محلية حقيقية، ولا يعيد المثال هنا ادعاء نجاح كل اتصال بالمستودع. النموذج التجريبي 135M إنجليزي محدود؛ لا تصفه بأنه نموذج عربي قوي. لا حدود اصطناعية لأسماء خادمك، لكن تشغيل مجلد محلي مقيد بعمارة causal LM تدعمها Transformers وبـsafetensors دون remote code. device=auto يختار CUDA المتاح للمحرك أو CPU؛ لم يتوفر GPU لاختباره. model_plan تقدير وزن/هامش لا يضمن fit ولا يحسب KV cache أو كل التكميم والتوازي. لا تنزيل تلقائي لنموذج 70B لمجرد أن حساب حجمه ممكن.

6. Ollama وvLLM والخدمات الخارجية

from alfarouqai import AI, Config
# Requires your already running compatible inference server. Not a live-service test.
r = AI("Explain Python briefly.", model="YOUR_SERVER_MODEL",
       backend="compatible", endpoint="http://127.0.0.1:8000/v1",
       config=Config(allow_network=True))
print(r.data)

backend="ollama" يوجّه إلى Ollama مع endpoint صريح أو localhost الافتراضي. اختبرت بروتوكولات Ollama/OpenAI-compatible بخادم مرجعي يستخدم نموذجاً حقيقياً؛ لم يشغّل daemon Ollama أو vLLM الأصلي هنا. للخادم البعيد استخدم HTTPS و Config(allow_network=True, allow_remote=True)، وapi_key_env="YOUR_API_KEY_VARIABLE" بعد وضع المفتاح في secrets/متغير البيئة خارج الكود. لا تشارك المفتاح في notebook. تنصيب خادم ضخم وتوزيع GPU والتكميم مسؤولية بيئة الاستدلال، لا وعد من البوابة.

7. البيئات والهاتف

VS Code: افتح المجلد ثم Python: Select Interpreter واختر .venv. PyCharm: اختر Existing Interpreter نفسه. Terminal وdebugger يجب أن يستعملا المفسر نفسه. Jupyter: ثبّت ipykernel في البيئة واختر kernel الصحيح. Colab/Kaggle: ارفع ZIP أو wheel وفكّه داخل runtime ثم %pip install /path/to/wheel.whl، غيّر current working directory إلى جذر المصدر لأمثلة guide_support. أسرار الحساب من Secrets لا من النص. storage المؤقت يزول؛ نزّل النتائج. تفعيل accelerator لا يعني أن كل خدمة تستعمل GPU؛ التحقق المحلي لا يثبت تشغيل كل منصة أو Windows/macOS. Hugging Face Spaces: راجع deploy/huggingface؛ الأمر يحتاج حساباً وتراخيص وموارد. GitHub Codespaces: شغل نفس بيئة Python مع مراعاة حدود ومسؤولية تكلفة المزود. الهاتف لقراءة HTML/Markdown وتنزيل ZIP وفكّه؛ للحساب استعمل متصفح Colab أو خادمك. Python+PyTorch على Android ليس مساراً مختبراً ولا نوعد بتثبيت CUDA أو TensorFlow فيه.

8. الخدمات والمشروعات العملية

مرجع ALFAROUQ_AI_COMPLETE_CODING_GUIDE.md يتضمن جميع القدرات المسجلة، تهيئة بيانات تعليمية، لكل خدمة كود نُفذ فعلياً ومقتطف ناتج ومحرك. شغّل من جذر المشروع python examples/guide/arabic_process.py مثلاً، ثم بدّل المدخلات ببياناتك. مجموعة الأمثلة ليست قياس جودة مستقل. المراجع/الfixtures بيانات تعليمية مصطنعة إلا صورة المؤسس ومعلومات النماذج. المشروعات المقترحة: 1. مقرر NLP عربي: تنظيف وتطبيع وISRI واستخراج خصائص، تدريب Pipeline TF-IDF+LogisticRegression وتقييم واختبار نصوص جديدة وحفظ النموذج. المواضيع LDA والتشابه اللفظي ليسا embeddings. 2. مشروع مبيعات: CSV بتواريخ ISO وأشهر مكتملة، تنبؤ زمني مع baseline وحدود. راجع الأشهر المفقودة ولا تستخدم التقسيم العشوائي لتقرير أداء السلاسل الزمنية. 3. مصنع: حساسات وSPC وإنتاجية ومقارنة مرجعية للصور وصيانة مسماة؛ لا كاشف عيوب شامل، لا سلامة تشغيل آلي، لا RUL، ولا اختبار PLC مادي. MQTT/Modbus/Serial بموافقة فقط. 4. مطور: مراجعة AST وملخص SQLite وتوليد كود/اختبارات غير موثوقين ومراجعتهم يدوياً. code.test يشغل كوداً يملك المستخدم ثقته؛ subprocess ليس عزلاً أمنياً. 5. باحث: قراءة ملفات وRAG ومصادر وتصدير وتقارير؛ تحقق من إجابات النموذج والحقوق. 6. مؤسسة: تجميع CSV ومطابقة دفاتر مالية وإخفاء أنماط بيانات تقريبياً؛ لا اعتماد طبي/مصرفي/تشريعي ولا ادعاء امتثال شامل.

9. المشاكل والأمان

MissingDependency: ثبّت extra في نفس البيئة. ConsentRequired: راجع سبب طلب الشبكة أو النموذج أو الأجهزة، ثم وافق قصداً. UnsupportedTask: عين task صريحاً أو Inputs. ValidationError: اقرأ الأعمدة والحدود والملفات. نفاد الذاكرة: أغلق Model واستعمل عمليات معزولة أو نموذجاً أصغر أو endpoint؛ لا تشغّل جميع النماذج معاً على 2GB RAM. لا تحفظ مفاتيح أو بيانات مرضى في Git. لا تفك pickle مجهولاً، استخدم safetensors لشبكات PyTorch وskops بمراجعة trusted types. RAG قد يتلقى prompt injection من المستند؛ المصدر غير الموثوق بيانات لا تعليمات. API يحتاج TLS ومراجعة أمان وحدود حمل قبل الإنتاج. النماذج تولد أخطاء وقد تكون منحازة؛ الإنسان صاحب القرار.

10. التطوير والتحقق والترخيص

اقرأ CONTRIBUTING.md، استخدم venv وpytest، ولا تغير اسم خدمة قديمة دون migration. run_verification.py ينفذ عمالاً معزولة؛ --installed يتحقق من wheel دون src path. verify_coding_guide.py يعيد تنفيذ نصوص الدليل مع أوزان وبرامج النظام الجاهزة. الترخيص الحالي للكود الأصلي Apache-2.0 تنفيذاً لطلب المصدر المفتوح الأحدث، مع بقاء حقوق التأليف لخالد سلمان. هذا يمنح حقوق استعمال/تعديل وفق الرخصة ولا يعني منع الجمهور من النسخ؛ هوية وصورة المؤسس محفوظتان بشروط مستقلة. تراخيص أوزان/بيانات المكتبات لا تنتقل تلقائياً إلى رخصة المشروع. لم يتم نشر شيء علناً. دليل المالك خاص ويستبعد من staging النشر. شروط «لا نسخ مطلقاً» لا تجتمع مع source open OSI.

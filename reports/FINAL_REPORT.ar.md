# تقرير تطوير وتسليم AlFarouq AI 0.2.0 Alpha
**2026-11-15 — تطوير إضافي للإصدار 0.1.0؛ لم ينشر المشروع علناً.**

## 1. ما الذي استمر وما الذي تغير
حوفظ على ملفات الاختبارات الأصلية الثلاثة دون تعديل، ونجحت اختباراتها الـ79.
حوفظ على الأدوات والواجهة القديمة، وأضيفت وحدات جديدة وتوسعات للواجهة والاعتماديات
وإدارة دورة حياة النماذج. الصورة الأصلية وبطاقتها لم تتغيرا، والاسم وبيانات المؤسس
والبريد محفوظة. أضيف منع الاشتقاق صراحة إلى الترخيص الخاص، دون أي ترخيص استخدام
عام للكود الأصلي. سجلات 0.1.0 محفوظة في reports/releases/0.1.0.

أصبح السجل يضم **40 قدرة**، منها **36 لها دليل تنفيذ محلي** بين الأدوات القديمة
والجديدة. الأربع الباقية موضحة أدناه. عدد الواجهات لا يساوي عدد نماذج مستقلة، ولا
يثبت اكتمال كل أبحاث الذكاء الاصطناعي أو التفوق على المكتبات العالمية.

## 3. نماذج مدربة شغلت فعلياً
| المجال | النموذج/المحرك والدليل | الحدود |
|---|---|---|
| نصوص وNLP وكود | SmolLM2-135M-Instruct، توليد وتصنيف احتمالي واقتراح كود وإصلاح | صغير وإنجليزي أساساً؛ لا جودة عربية متقدمة أو صحة كود مضمونة |
| كشف أشياء | SSDlite320/MobileNetV3 بأوزان COCO | أصناف محدودة، لا هوية أشخاص |
| تصنيف صور | MobileNet V3 Small بأوزان ImageNet | فئات ImageNet لا وصف شامل |
| تقسيم صور | LRASPP/MobileNetV3 بأوزان VOC | class-ID mask فعلية؛ ليس instance segmentation |
| فيديو وتتبع | كشف مدرب + centroid IDs على مقطع مصدره الصورة المرفقة | مؤقت ومعرض لتبديل الهوية عند التداخل؛ لا فهم أفعال |
| صوت إلى نص | Whisper tiny / CTranslate2 CPU-int8 | اختبر صوتاً إنجليزياً مولداً؛ أخطأ بعض الكلمات |
| نص إلى صوت | espeak-ng منفذ خارجي أنتج WAV فعلياً | formant synthesis، ليس TTS عصبياً أو استنساخ صوت |
| OCR | Tesseract وحزم eng/ara على نصوص مطبوعة | جودة المسح والخط اليدوي ليست مضمونة |
| تضمين وبحث | multilingual MiniLM-L12-v2 + FAISS IndexFlatIP + SQLite | بحث عابر للغات فعلي؛ 10000 مقطع سقفاً، لا قاعدة موزعة |

الأوزان الستة نزلت فعلياً وحفظت مراجعات المصدر وبصمات الملفات في model-manifests.
لا أوزان عشوائية سميت اختبار استدلال ناجحاً. مجموع أوزان التحقق نحو 847 MB خارج
حزمة المصدر؛ لم تضخّم النواة أو الأرشيف. يتطلب أول استعمال على جهاز جديد تنزيل
النموذج بموافقتك، ثم يمكن العمل من cache محلياً. لا API مدفوع إلزامي.

## 4. خدمات إضافية شغلت
- شبكة PyTorch متعددة الطبقات: تصنيف وانحدار وتقييم وحفظ safetensors وJSON ثم
استعادة النموذج ومقارنة التنبؤ. ليست API تدريب CNN/Transformer أو finetuning.
- تنبؤ خط اتجاه بتقسيم زمني، وتوصيات collaborative cosine، وIsolationForest
دفاعي؛ baselines حقيقية محدودة، لا AutoML شامل ولا إثبات هجوم.
- RAG يعيد مصادر وإزاحات ويولّد جواباً من السياق؛ لا ضمان لصحة الإسناد أو منع
الهلوسة. أضيفت هوية نموذج قابلة لنقل cache بين الأجهزة.
- وكيل لغوي اختار ونفذ **1 أداة** في عينة التحقق ثم ولّد مراجعة؛ مخطط ومراجع
يشتركان في النموذج نفسه، لا عقول أو نماذج مستقلة. قائمة الأدوات ثابتة والمدخلات
من المستخدم، ولا تنفيذ أكواد يكتبها النموذج. AgentTeam السابق محفوظ.
- Scheduler دائم في SQLite يشغّل المهام عند tick فقط؛ ليس خدمة دائمة ولا
exactly-once بعد انهيار العملية. أتمتة محلية حقيقية لا تشغيل خلفي مخفي.
- MQTT نشر وقراءة مع وسيط Mosquitto محلي حقيقي وQoS1 ACK. Serial قراءة/كتابة
على pseudo-terminal حقيقي بنواة Linux. لا أجهزة مادية أو روبوتات اختبرت.
- code.test شغّل unittest لمشروع اختبار موثوق. العملية والمهلة ليستا sandbox
أمنياً، ولا يجوز تشغيل كود مجهول تلقائياً.
- اختبر مسار التثبيت الشبكي لإضافة iot في venv مُدارة واستيراد حزمها بمفسرها.
اختبر skops save القديم فعلياً، وكذلك SemanticIndex القديم بأوزان تضمين فعلية.

## 5. جودة النتائج ليست ادعاءً تسويقياً
نطقت عينة الكلام: Hello world. This is a speech recognition test.
أما التفريغ الفعلي فكان: **The Long World. This is my speech recognition test.**. احتفظنا بالخطأ ولم نستبدل الناتج بنص متوقع.
عينات الرؤية والصوت والـOCR تعليمية صغيرة، لا benchmark علمي أو دليل دقة عامة.
مقاييس التدريب المصطنع لا تثبت التعميم. لا ادعاء «أقوى نموذج» أو «الأفضل عالمياً».
أزمنة Result تشمل التحميل غالباً، ولا تقارن مباشرة بقياس warm inference.

## 6. المشكلات التي ظهرت وعولجت وحدود الموارد
فشل faster-whisper مع PyAV 19 بسبب metadata_errors؛ عولج بتقييد av>=11,<16
وأعيد الاختبار. أوقف النظام جولة تجمع نماذج كثيرة في عملية واحدة بسبب ضغط
الذاكرة؛ أضيف إغلاق صريح للنماذج ومخازن المتجهات، ونص تحقق بعمليات متتابعة
مستقلة. لهذا لا ندّعي أن تشغيل جميع النماذج معاً في 2GB آمن. لم يتم تدقيق أمان
مستقل أو فحص ثغرات شامل أو اختبار GPU/Windows/macOS. ملفات متطلبات الاختبار
جرد إصدارات لا lock محمولاً ولا ضمان أمان أبدي.

## 7. ما لم يكتمل أو لم يُختبر فعلياً
1. **image.generate وvideo.generate**: تكامل Stable Diffusion/CogVideoX تجريبي،
اختبرت بواباته فقط، ولم يشغل استدلال بأوزان فعلية. الذاكرة/العتاد المتاحان لا
يكفيان للتحقق المسؤول من نماذج الفيديو؛ يلزم جهاز مناسب ونموذج وترخيص وتقييم.
2. المساران القديمان **llm.chat عبر Ollama** و**image.objects عبر Transformers**
لم يختبرا بأوزان فعلية هنا؛ البديلان الجديدان local.generate وvision.detect
اختبرا فعلاً. لم نحذف المسارين أو نعد تسميتهما وكأنهما اختبرا.
3. لا ROS/SLAM أو تحكم روبوت مادي أو حساسات فعلية؛ يلزم العتاد وبروتوكول
وسلامة وموافقة خاصة. نجاح رسالة MQTT ليس إثبات حالة محرك.
4. لا fine-tuning لنماذج كبيرة، ولا فيديو توليدي مختبر، ولا صوت عصبي طبيعي،
ولا تقييم شامل للعربية أو اختبار RAG faithfulness أو تصحيح تلقائي مضمون للكود.
5. أمثلة Colab/Kaggle/Jupyter وقالب Hugging Face وGitHub/PyPI مجهزة محلياً،
لكن لم تشغل تلك المنصات أو الحاوية أو Gradio. الدفتر تحقق JSON وصياغة خلاياه
محلياً فقط. لم يحجز اسم أو ينشأ مستودع خارجي أو تنشر حزمة أو Space أو Dataset.

## 9. التشغيل والتسليم
ابدأ بـ docs/index.html ثم الكتاب. ثبّت من مجلدك أو wheel المرفق، لا تفترض
ملكية اسم PyPI. الاستدعاء بعد الإعداد والموافقات يكون سطراً أو سطرين مثل:
```python
ai = Client(Config(allow_network=True, allow_model_download=True))
r = ai.run('vision.detect', image='photo.jpg')
```
هذا لا يلغي تثبيت إضافة torchvision/vision أو متطلبات الجهاز. تعاد النتائج
كـResult وتصدر JSON/CSV/MD/HTML/TXT؛ الملفات الحقيقية للصوت والـmask والتقارير
في v0.2-model-results. الأرشيف يحتوي المصدر والوثائق والأمثلة والاختبارات
والهوية وحزم التوزيع وأدلة التشغيل، لا أوزان النماذج أو بيئات venv.

جُهز مسارا تسليم: أرشيف صغير ورابط ملف داخل AI Drive الخاص بالمالك. لا يمكن
لهذه المكتبة أو لهذا التقرير إلغاء اشتراك المنصة أو ضمان سياسة تنزيلها؛ لم
تنشر الملفات على مضيف عام دون موافقتك. تحقق ZIP وفك الضغط والبصمات يسجله نص
validate_project.py، وبصمة الأرشيف في الملف المرافق.

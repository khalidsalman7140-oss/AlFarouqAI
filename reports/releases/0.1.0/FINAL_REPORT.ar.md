# تقرير تسليم AlFarouq AI — 0.1.0
**تاريخ التسليم: 2026-11-14. الحالة: Alpha محلي، لا نشر خارجي.**

## الخلاصة الصادقة
تم تسليم مشروع Python فعلي قابل للتثبيت والبناء والتطوير، وليس خطة أو هيكلاً
فارغاً. يضم نواة خفيفة، 13 قدرة مسجلة، وكلاء تخصصية محدودة، استرجاعاً نصياً،
توثيقاً عربياً وإنجليزياً، صفحة تعريف محلية، اختبارات وأمثلة وملفات توزيع.
**لم تكتمل الرؤية الشاملة لكل المجالات المطلوبة بعد**؛ هذا إصدار تأسيسي عامل،
لا منظومة إنتاجية مكتملة ولا ضمان أن أي وصف طبيعي سيُنفذ تلقائياً.

### لا تحوّل نجاح العينات إلى دعاية دقة
مقاييس التصنيف التعليمي الفعلية: `{"accuracy": 1.0, "f1_weighted": 1.0}`.
مقاييس الانحدار التعليمي الفعلية: `{"mae": 1.3899999999999992, "r2": 0.9994260470360056}`.
هذه بيانات مصطنعة صغيرة، لا benchmark علمي ولا تقدير دقة على بيانات حقيقية.
أُزيل عمود score المشتق من مثال تصنيف الطلاب للحد من تسرب الهدف.

## ما كُتب كموصل ولم يُشغّل بأوزان فعلية
Ollama chat/vision، faster-whisper، Transformers object detection، وSemanticIndex
المبني على SentenceTransformers. لا أوزان مرفقة ولا تنزيل أوزان أثناء التسليم.
اختُبر بروتوكول Ollama بخادم محلي اختباري معلن، لا بنموذج لغوي؛ ليست الاستجابة
الاختبارية قدرة إنتاجية أو نتيجة ذكاء مصطنعة تسلّم للمستخدم كاستدلال حقيقي.
مسار حفظ skops ومسار تثبيت extras الشبكي لم يختبرا نجاحاً؛ اختبرت بوابات الموافقة
ومنع التعديل على بيئة غير مُدارة. لا واجهة تحميل نموذج محفوظ حالياً.
**لم يُجر ادعاء بتشغيل «أقوى نموذج» أو مقارنة نماذج كبيرة.** لم تُشغّل نماذج
خارجية مدفوعة ولم يُفرض API مدفوع. اختيار النموذج الأمثل يتطلب قياس مهمة وعتاد
وترخيصاً، ولا يصح استبدال الدليل باسم تسويقي.

## ما لا يزال يحتاج تطويراً
تدريب شبكات عميقة وfinetuning، توليد صور/فيديو/TTS، OCR عربي، تتبع متعدد أهداف،
RAG توليدي مع استشهاد وامتناع، وكلاء لغوية مستقلة، تكامل أجهزة IoT وروبوتات،
جدولة دائمة، sandbox عمليات وحدود CPU/RAM وإلغاء، إدارة تجارب ونماذج، مراقبة
وانحياز وخصوصية، تقييمات عربية واقعية وتدقيق أمني مستقل. راجع
[مصفوفة المجالات](../docs/ar/capabilities.md) وخارطة التطوير بمعايير قبول.
الموجّه ثنائي اللغة محدود وليس LLM عاماً؛ يرفض الغموض ولا يخمن target/problem.
المراجع يتحقق من البنية لا الحقيقة. Timeout يحد HTTP فقط. لا عزل نظام تشغيل.
تعمل الوظائف المختبرة محلياً؛ لم تختبر Windows/macOS/GPU أو كل نسخ Python هنا.

## سجل التحقق والتصحيح
كشف التشغيل الأول غياب CascadeClassifier في OpenCV 5 الموجود على المضيف.
قُيّد vision إلى >=4.10,<5 واختبر OpenCV 4.12 في بيئة نظيفة مستقلة، دون حيلة
إرجاع نتائج ثابتة. صُحّح توقع حجم الصورة في الاختبار بعد قياس الأصل الفعلي
720×1600؛ لم تُغيّر الصورة لتوافق الاختبار. نجحت كل الاختبارات بعد التصحيح.

## بدء الاستخدام بعد فك ZIP
1. افتح docs/index.html لقراءة الصفحة المحلية؛ لا تحتاج شبكة أو خادماً.
2. أنشئ وفعّل .venv، ثم نفّذ `python -m pip install .` من مجلد المشروع.
3. شغّل `python examples/01_quickstart.py`.
4. للتعلم الآلي ثبّت `python -m pip install '.[ml]'` ثم شغّل المثال 02.
5. اختر مفسر البيئة داخل VS Code. لا تفترض ملكية اسم alfarouqai في PyPI.

النسخة المجلدية محفوظة في مساحة عمل التسليم، والـZIP نسخة منظمة قابلة للتنزيل
وليست مستودعاً منشوراً أو استضافة إنتاجية أو وعداً بحفظ سحابي دائم خارج المحادثة.
تفاصيل بصمات الملفات وسلامة الأرشيف في DELIVERY_MANIFEST.json وarchive-validation.json.

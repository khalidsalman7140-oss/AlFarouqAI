تاريخ التحقق: 2026-11-19. الكود الحالي Apache-2.0؛ حقوق المؤلف لخالد سلمان من اليمن.

ما المكتبة وما حدودها؟

بوابة Python محلية أولاً لأدوات AI وتحليل البيانات وخدمات عملية. تعيد نتائج حقيقية مع backend وتحذيرات ومصدر، ولا تخلق عتاداً أو دقة أو صلاحية قانونية. كل مثال خدمة قابل للتشغيل أدناه نُفذ من النص نفسه، وسجله ومخرجاته في reports/coding-guide-results. ثلاثة موصلات غير مختبرة مفصولة بلا مثال نجاح وهمي.

التثبيت والإعداد

من المجلد المفكوك أنشئ بيئة: python -m venv .venv ثم فعلها بالطريقة المناسبة لنظامك: .venv\Scripts\Activate.ps1 في PowerShell أو source .venv/bin/activate في Linux/macOS. ثبّت من المصدر python -m pip install . أو wheel المرفق في dist. لا تفترض أن الاسم العام على PyPI محجوز للمشروع قبل التحقق من النشر الفعلي.

النواة بلا اعتماديات تشغيل إلزامية. أضف فقط ما تحتاجه، مثل python -m pip install '.[nlp,ml]'. الإضافات الفعلية: ml، vision، documents، speech، semantic، objects، persistence، local، torchvision، deep، vector، iot، diffusion، nlp، api، onnx، tensorflow، industrial، gdrive، dev. المحركات الثقيلة اختيارية؛ قد تحتاج برامج نظام مستقلة مثل Tesseract وحزم eng/ara وespeak-ng وMosquitto. PyTorch CPU wheels تقلل تنزيل CUDA غير المطلوبة؛ اتبع إرشادات نظامك الرسمية. Python 3.10+ مستهدف، والتنفيذ المحلي هنا Python 3.12/Linux/CPU. لا تدّعي مصفوفة CI أن Windows/macOS أو Colab/Kaggle/Hugging Face قد اختبرت فعلياً في هذه المهمة.

الشبكة والأوزان والمفاتيح

لا تنزيل أو تثبيت خفي عند import. config.allow_network وallow_model_download موافقتان صريحتان. models تحت ~/.cache/alfarouqai/models أو ALFAROUQ_MODEL_HOME. راجع الرخصة والحجم والمراجعة المثبتة قبل الموافقة. لا أوزان ضخمة داخل ZIP. api_key_env يستقبل اسم متغير البيئة لا قيمة المفتاح. لا تضع الأسرار في المصدر أو notebook؛ استعمل مدير أسرار بيئتك. Remote endpoints تحتاج allow_remote وHTTPS. سكربت Google Drive يحتاج OAuth منك؛ لم يُربط حساب Google أثناء التسليم.

بوابة سطر واحد وموديل كبير حسب الموارد

اختبر المثال التالي بأوزان حقيقية مخزنة محلياً:

from alfarouqai import AI
result = AI('What is the capital of France?', model='smollm2-135m', max_new_tokens=24)

كما اختبر AI على prompt عام بلا model؛ هذا افتراض محلي للتوليد النصي، لا إذن بتنفيذ أوامر النظام أو تحكم صناعي. التحليل ذو الملفات أو الهدف الواضح يختار الخدمة المدعومة؛ الغموض أو نقص target/reference لا يملآن بالتخمين.

Model جلسة قابلة للاستعمال المتكرر مع close/with. backend local يقبل النموذج المختار أو مجلد causal-LM محلياً متوافقاً مع Transformers، لا كل معمارية. backend ollama أو compatible يمرر اسم النموذج إلى خادمك، وهو الذي يتحمل العتاد. Model/AI model gateway يدعمان device=auto/cpu/cuda؛ اختبر CPU ورفض CUDA غير المتاح، ولم يختبر استدلال GPU فعلي. environment وmodel_plan أدوات تقدير لا ضمان fit. تقدير weights لا يحسب KV cache والسياق والدفعات والتكميم كاملاً. لا وعد بتشغيل أكبر نموذج على الهاتف؛ اقرأ الدليل فيه وشغّل الحساب على عتاد مناسب أو endpoint.

النتائج والتصدير والأخطاء

Result.to_dict يعرض البيانات والمحرك والتحذيرات. export يدعم JSON/CSV/MD/HTML/TXT؛ هذه الصيغ اختبرت. CSV يصدّر rows إن وجدت وإلا مفاتيح/قيماً؛ HTML يهرب النصوص. الكتابة ترفض الملف القائم إلا overwrite=True. أعد تهيئة OUT عند تكرار مثال ينشئ ملفاً جديداً. زمن المثال يتضمن التحميل ولا يصلح وحده لمقارنة أداء النماذج. Config(verbose=True) يعرض start/done/backend/error type في stderr دون طباعة المفاتيح أو المحتوى الخاص. لا ادعاء نسبة تقدم داخل كل نموذج خارجي.

MissingDependency: ثبت extra في المفسر الذي تستعمله. ConsentRequired: لم تمنح صلاحية الشبكة/التنزيل/الأجهزة/تشغيل الكود. ValidationError: مدخل ناقص أو غير صالح. أخطاء المحرك الأصلية قد تنتقل كذلك. Config.timeout يحد HTTP وبعض أدوات النظام، وليس sandbox عاماً أو حداً مضموناً لكل CPU/RAM. code.test يختبر كوداً موثوقاً فقط؛ -I والمهلة لا تمنعان وصوله إلى الملفات والشبكة. لا تنفذ اقتراح LLM تلقائياً.

مشاريع تجمع الخدمات

  • طالب NLP: arabic.process للاحتفاظ بالنص المنظف، nlp.train للتصنيف المسمي، ثم TextModel.predict. إزالة التكرار لا تمنع تسرب المؤلف/الموضوع/الزمن؛ قيّم تقسيماً مناسباً. ISRI اشتقاق تقريبي لا lemmatizer سياقي، وTF-IDF لفظي لا دلالي.
  • مصنع: اجمع industry.sensors ثم industry.control على baseline مستقلة، وفحص industry.defects بصورة مرجعية مصطفة، ثم industry.production. لا تساوِ control limits مع specification limits، ولا تدّعِ OEE دون مدخلاته. الصيانة مصنف labels تاريخي لا عمر متبقٍ أو shutdown آلياً؛ يلزم تقييم مجمّع حسب الآلة والزمن.
  • شركة: sales.forecast يجمع شهوراً مكتملة بصيغة ISO ويتحقق زمنياً. ليس وعد مبيعات ولا سببياً. finance.reconcile Decimal لمطابقة الدفاتر لا موافقة تحويل مالي أو كشف احتيال مثبت. database.profile يقرأ المخطط والعد دون تعديل قاعدة البيانات.
  • مستشفى: data.group لبيانات مواعيد مجهولة الهوية وزمن الانتظار؛ privacy.redact يخفي بريد/هاتف تقريبياً وليس امتثال HIPAA/GDPR أو تعمية كاملة. لا تشخيص أو علاج.
  • مستندات: document.read -> rag.index -> rag.search.semantic -> rag.answer. المصادر والإزاحات متاحة، لكن entailment وصحة الاستشهاد غير مضمونين. PDF مصور يحتاج OCR غير موصول تلقائياً بكل الصفحات. لا تعتبر جواب النموذج مرجع حقيقة.
  • وكلاء: AgentTeam حتمي وLLMAgent يختار من قائمة آمنة؛ الأدوار تشترك في نموذج لا عقول مستقلة. Scheduler ينفذ عند tick ولا يعمل وجهازك مغلق. MQTT ACK ليس إثبات فعل جهاز. Serial/Modbus اختبرا بوسيط/خادم محلي وPTY، لا PLC/روبوت مادي.

سياق أمثلة الاتصالات

model_server يشغّل LLM حقيقياً عبر بروتوكول مرجعي؛ لا يعني تثبيت vLLM/Ollama. broker يحتاج Mosquitto محلياً؛ modbus_server خادم محلي للاختبار. مثال PTY خاص بـLinux/POSIX، وعلى Windows تحتاج منفذ COM حقيقياً وبروتوكولاً مصرحاً. لا مسح شبكات أو إرسال أوامر أجهزة دون موافقة. API النصية محكومة بمفتاح وقائمة صغيرة؛ لا يغني هذا عن TLS وحدود موارد ومراقبة وتدقيق أمان إنتاجي.
